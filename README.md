# Centralized Banking CCTV Surveillance — 64 Branches

**National multi-site surveillance infrastructure | Lead Project Engineer | Delivered in under two weeks (project owner account)**

![Centralized CCTV conceptual architecture](assets/architecture-central-monitoring.svg)

> **Important:** All 64 branches contain IP cameras and network connectivity equipment. **Live video monitoring and operator display screens are located ONLY in the single central monitoring room at the head office. There are no local CCTV preview screens in the branches.**

## Project overview

Led engineering design, technical configuration and delivery of a centralized surveillance and recording environment connecting **64 bank branches across multiple cities** with a head-office surveillance platform. Working with a specialist field installation team, the project was completed within two weeks, as reported by the project lead.

## Responsibilities
- Select cameras and recording equipment.
- Design system architecture and surveillance network interconnection.
- Define VLAN-based traffic segmentation and optimize bandwidth use.
- Configure network and NVR systems and integrate ONVIF/RTSP video feeds.
- Equip the **single head-office monitoring room** and central video wall.
- Supervise branch installation teams, commissioning, operations and technical handover.

## Architecture and stream flow

`Branch IP cameras → branch access switching / routing → WAN → central core → recording / stream distribution → head-office monitoring room`

**Branch sites:** cameras, access switching, network edge. **No local monitoring workstations or live preview.**

**Head office:** core switching and routing, centrally managed recording, distribution NVRs, monitoring clients and operator displays, all in the headquarters/data-center environment.

The network image is a **conceptual illustration, not an actual as-built production topology**. Labels, symbols, VLAN numbering and network paths are illustrative and do not disclose the bank's production settings.
