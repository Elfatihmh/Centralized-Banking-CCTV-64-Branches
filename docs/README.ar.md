# منظومة المراقبة المصرفية المركزية — 64 فرعًا

**الدور:** المهندس الرئيسي للمشروع · **النطاق:** 64 فرعًا مصرفيًا · **مدة الإنجاز:** أقل من أسبوعين بحسب توثيق صاحب المشروع.

![الرسم المعماري التصوري](../assets/architecture-central-monitoring.svg)

## توضيح معماري أساسي

**توجد كاميرات المراقبة ومعدات الربط في الفروع، لكن لا توجد شاشات عرض أو معاينة محلية داخل أي فرع. جميع شاشات العرض والمراقبة الحية موجودة في غرفة مراقبة مركزية واحدة في رئاسة المصرف فقط.**

## وصف المشروع

قيادة التصميم الهندسي والتنفيذ الفني لمنظومة مراقبة مركزية تربط 64 فرعًا عبر شبكة واسعة بمنظومة تسجيل وإدارة ومشاهدة موحدة في المقر الرئيسي.

## المسؤوليات

- اختيار الكاميرات وأجهزة التسجيل.
- تصميم هندسة الشبكات ومنظومة المراقبة.
- تنظيم حركة الفيديو والإدارة باستخدام VLAN.
- ضبط أجهزة الشبكة والتسجيل وتكامل ONVIF وRTSP.
- تجهيز غرفة المراقبة الوحيدة في المقر الرئيسي، والشاشات ومحطات المشغلين.
- الإشراف على الفنيين في الفروع، والتشغيل والاختبارات والتسليم.

**مسار الخدمة:** كاميرات الفروع ← معدات الشبكات في الفروع ← الشبكة الواسعة ← المركز الرئيسي ← أجهزة التسجيل وتوزيع البث ← غرفة المراقبة المركزية.

الرسم توضيحي فقط، ولا يكشف البنية التنفيذية الفعلية أو هوية المصرف أو عناوين شبكاته.
